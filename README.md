# AvalonLotus Install

Setup scripts that prepare a new computer for AvalonLotus work.

| Folder | Platform | Start here |
|---|---|---|
| [`Mac/`](Mac/README.md) | macOS | `bash "Mac/install.sh"` |

## One-Line Install: Mac

Sign in to the App Store first, then run this in Terminal:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/AvalonLotus/AvalonLotus-Setup-Install/main/Mac/bootstrap.sh)"
```

It downloads this repo and runs `Mac/install.sh`; see [`Mac/README.md`](Mac/README.md) for what it installs.
